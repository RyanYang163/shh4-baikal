## 简介

轻量 CalDAV / CardDAV 服务器：手机与电脑原生日历、通讯录同步。

## 打包

```bash
./build.sh                # 默认 x86_64
./build.sh aarch64        # ARM（Deb 应用）
```

产物在 `build/output/`，同级生成 `<包名>.sha256`。
